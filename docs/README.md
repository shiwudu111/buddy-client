## 五、使用建议
- 遇到“应该按什么做”时，先看冻结决策。
- 遇到“接口怎么对”时，优先看接口基线。
- 遇到“数据库怎么落”时，优先看数据库基线。
- 遇到“当前做到哪”时，看阶段进度报告。
- 遇到“旧资料还要不要参考”时，去归档目录查历史版本。
