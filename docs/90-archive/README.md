# 90-archive 说明

本目录用于存放 **当前仓库内已过期、已被替代、或只保留历史参考价值** 的文档。

## 归档原则

- 阶段性进度报告归档到这里
- 提审报告、历史汇总、一次性过程材料归档到这里
- 已被新冻结文档替代的旧文档，可在确认后归档到这里

## 使用规则

1. 归档文档默认不再作为当前开发、联调、review、验收依据。
2. 若需要追溯历史上下文，可以阅读归档文档，但不得用它覆盖当前冻结口径。
3. 新归档内容建议按日期建子目录，例如：
- `2026-04-14-阶段报告归档/`
- `2026-04-14-文档整理归档/`
