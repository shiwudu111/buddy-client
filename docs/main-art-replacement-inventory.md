## First Replacement Slice

Do not replace the full UI shell until the following art assets exist:

1. `main_panel_9slice.png` for left/right panels.
2. `main_bubble_9slice.png` and `main_bubble_tail.png` for pet speech.
3. `main_dock_9slice.png` for the bottom dock.
4. A unified six-icon action set for feed/play/bath/sleep/music/care.

Recommended first code slice after assets arrive:

1. Add texture paths to `MainAssetStore.ts`.
2. Replace the pet bubble skin first because it is isolated to `MainStageRenderer.ts`.
3. Replace left/right panel skins next because they are visually important but mostly static.
4. Replace dock and action button skins last because they affect click targets and mobile layout density.

## Keep Procedural For Now

- Responsive layout boxes and masks.
- Hit target containers.
- Debug/diagnostic panels.
- Fallback stage background when image assets fail.
- Lightweight shadows generated by `MainProceduralTextureFactory`.

## Acceptance

- Phone-landscape first glance remains pet-first.
- Text remains readable after replacing skins.
- No new asset blocks Main scene loading if a texture fails.
- Android Native keeps ArtDebugBridge disabled.
- DevLog visibility follows diagnostics mode, not art replacement state.
