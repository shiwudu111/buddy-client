# 客户端联调验收清单 V1.0

## 文档信息
- **整理时间**：2026-04-03
- **适用阶段**：MVP 联调期
- **适用对象**：客户端、后端、测试、项目负责人

## 目标
用于在当前 MVP 阶段统一客户端联调验收口径，确保学生端与家长端在关键主链路、异常态和提示文案上达到可交付的最小标准。

## 验收结果标记建议
- 通过
- 失败
- 部分通过
- 被后端阻塞
- 待确认

## 一、学生端验收

### 1. 登录与会话
- [ ] 可使用真实学生账号登录
- [ ] 登录后可进入学生端首页
- [ ] 退出登录后可返回登录页
- [ ] 重新登录后会话恢复正常

### 2. 宠物链路
- [ ] 无宠物账号可看到创建宠物入口
- [ ] 创建宠物成功后可显示宠物核心状态
- [ ] 已有宠物账号可正常显示宠物名称、等级、饥饿度、心情值、经验值
- [ ] 失效 `petId` 可自动回收，不会卡死在错误状态
- [ ] 无本地宠物映射时，刷新提示真实，不误报成功

### 3. 作业链路
- [ ] 可进入作业中心
- [ ] 学科切换正常
- [ ] 各学科草稿独立保存
- [ ] 提交作业后有明确成功 / 失败提示
- [ ] 今日作业状态可见
- [ ] 作业历史可见，且内容完整

### 4. 提示与稳定性
- [ ] 刷新提示与真实结果一致
- [ ] 空态与失败态提示可读
- [ ] 页面无明显卡死、白屏、错误跳转

## 二、家长端验收

### 1. 登录与空态
- [ ] 可使用真实家长账号登录
- [ ] 登录后可进入家长端首页
- [ ] 未绑定状态展示清晰
- [ ] 未绑定时点击刷新，提示为：`当前尚未绑定孩子，请先绑定后再刷新`

### 2. 绑定链路
- [ ] 支持按 `child_username` 绑定
- [ ] 支持按 `child_id` 绑定
- [ ] `child_id` 口径已确认是孩子账号 `User.id`
- [ ] 绑定成功后能加载孩子状态
- [ ] 绑定结果在重新登录后仍可恢复
- [ ] 当前已绑定其他孩子时，前端提示中文且符合 `409` 语义
- [ ] 孩子已被其他家长绑定时，前端提示中文且符合 `409` 语义
- [ ] 孩子不存在时，前端提示中文且符合 `404` 语义

### 3. 查看链路
- [ ] 可查看孩子宠物状态
- [ ] 未创建宠物的孩子可给出明确中文提示
- [ ] 可查看今日作业状态
- [ ] 可查看周报区域
- [ ] 周报接口未完成时可显示明确留壳提示

### 4. 界面与交互
- [ ] 右侧信息已按上下分区展示
- [ ] 今日作业区域支持上下滚动
- [ ] 周报区域支持上下滚动
- [ ] 不再直接在前端暴露孩子 ID
- [ ] 输入框旁边无异常 `label`
- [ ] 控制台不再出现 `Can't add renderable component to this node because it already have one.`

### 5. 刷新与会话
- [ ] 已绑定孩子场景下，刷新结果真实且稳定
- [ ] 退出登录后可返回登录页
- [ ] 重新登录后可恢复家长端状态

## 三、当前正式联调口径
- [ ] 当前正式只支持：`1 个家长 <-> 1 个孩子`
- [ ] 双家长绑定同一孩子不属于当前缺陷，而是未支持能力
- [ ] 绑定相关状态码语义已对齐：
  - `404`：孩子不存在
  - `409`：孩子已被其他家长绑定，或当前家长已绑定其他孩子
  - `403`：当前登录用户不是家长

## 四、通过标准建议
满足以下条件，可判定当前客户端达到本阶段联调验收标准：
1. 学生端主链路通过
2. 家长端主链路通过
3. 关键空态与异常态提示可读
4. 当前冻结口径下无阻塞性前端问题
5. 无持续复现的控制台高频错误

## 五、备注
- 若字段、路径或状态码与当前基线冲突，以冻结后的接口口径为准。
- 若环境切换，请先更新固定联调测试数据表，再执行本清单。
